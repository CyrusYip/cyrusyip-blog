开手动挡车要自己换挡，所以一定要学会不看挡把的情况下操作。

要挂挡做得好，就是做好三件事：

1. 记住挡位
1. 学会挂挡手法
1. 确认当前挡位

## 挡位规律

挡位排列的顺序是先从上到下，再从左到右，数字从小到大。知道规律就很好记了。

如下图所示：

```text {lineNos=false}
  1     3     5
  |     |     |
  |-----N-----|
  |     |     |
  2     4     6 
```

倒挡的位置不统一，请按照你车辆的说明书操作。

常见的倒挡挂挡方式如下：

- 下压挡把，挂入 1 挡的位置
- 上提挡把，挂入 1 挡的位置
- 有些 5 速变速箱的倒挡位置是右下角

## 挂挡手法

空挡左右两边有弹簧，会把挡杆推回空挡位置。你可以从空挡往左右两边推，放手之后挡杆会弹到空挡的位置。挂挡手法的窍门就是克服和利用回弹到空挡的力。

先介绍基本的操作手法（不要太用力抓挡把和推拉，可以抓稳和移动挡把即可）：

1. 左推：手心中间贴着挡把的右边，左推（克服弹簧的力）。
1. 左推前推（N -> 1）：保持左推的同时，用手腕前推。
1. 左推后拉（N -> 2）：保持左推的同时，用大拇指以外的手指握住挡杆，后拉。
1. 前推（N -> 3）：手心贴着挡把顶部，所有手指握着挡把，前推。
1. 后拉（N -> 4）：手心贴着挡把顶部，所有手指握着挡把，后拉。
1. 右推：手心的右下部分（大鱼际）贴着挡把左边，右推（克服弹簧的力）。这里没用手心中间贴挡把，是因为那样太难了，手不容易弯曲到那个程度。
1. 右推前推（N -> 5）：保持右推的同时，用手腕前推。
1. 右推后拉（N -> 6）：保持右推的同时，用大拇指以外的手指握住挡杆，后拉。

纵向的挡位（比如 1 和 2）可以直接切换。横向的挡位（比如 1、3、5）不能直接切换，必须中间经过空挡，比如不能在 1 挡的时候右推到 3 挡。

如果挂挡是两个动作（左推/右推+前推/后拉），第一个动作要够力，不然就会挂错挡。以 1 –> 2（左推后拉）为例，左推不够力的话，后拉的时候会进 N 挡，再进 3 挡。转速不匹配可能导致熄火。

挂错挡抬离合的时候，可能转速太低（车子抖动，严重就熄火）或者转速太高（突然大声，严重就车胎抱死或者变速箱损坏），这时候就要马上踩下离合，可以先回 N 挡（空挡）再考虑应该用什么挡位。

看文字可能觉得很复杂，实际上多操作几次就熟悉了。

建议拉好手刹开窗熄火练习，而且要踩离合，养成正确的习惯。

下面是挂挡操作的例子：

- 进空挡：往 N 挡的方向轻轻前推或者后拉，利用弹簧的力进 N 挡。也就是从 1/3/5 挡进 N 挡就轻轻后拉，从 2/4/6 挡进 N 挡就是轻轻前推。
- 升挡：
    -  N -> 1：左推前推。
    -  1 -> 2：左推后拉。
    -  2 -> 3：轻轻前推进 N 挡，再前推。
    -  3 -> 4：后拉，不用在 N 挡停留。
    -  4 -> 5（有些车这样难挂挡）：右推前推。
    -  4 -> 5（容易挂挡，但比较慢）：轻轻前推进 N 挡，右推前推。
    -  5 -> 6：右推后拉。
-  降挡：
    -  6 -> 5：右推前推。
    -  5 -> 4：轻轻后拉进 N 挡，再后拉。
    -  4 -> 3：前推，不用在 N 挡停留。
    -  3 -> 2（有些车这样难挂挡）：左推后拉。
    -  3 -> 2（容易挂挡，但比较慢）：轻轻后拉进 N 挡，左推后拉。
    -  2 -> 1：左推前推。
-  越级换挡（使用越级换挡请先了解转速匹配和越级换挡的风险）：
    -  3 -> 6（有些车这样难挂挡）：右推后拉。
    -  3 -> 6（容易挂挡，但比较慢）：轻轻后拉进 N 挡，右推后拉。
    -  5 -> 3：轻轻后拉到 N 挡，前推。

例子就写那么多了，手法就只有 8 种，换挡最多用 2 种手法，希望你可以举一反三。

## 确认当前挡位

练习挂挡的时候，在每个挡位都放手到挡把上感受，挡把会往挡位那边倾斜，所以感觉都是不一样的。多去感受和记忆，要做到手放下去就知道当前挡位。

有些车是没有挡位显示的，所以要学会摸挡杆来确定挡位。车子显示换挡提示的时候，也不会显示当前挡位，而是显示建议挡位。

有些车挡位杆摸着没明显的感觉，确认前方安全时可以偷瞄一眼。
